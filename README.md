# Music Player UI

A static music-streaming home page built with HTML and CSS, modelled on a Spotify-style layout. It is a UI practice project and does not play audio.

## What's on the page
- A top bar with icons (Font Awesome), a search field and links
- A "Popular artists" row of artist cards
- A "Popular Songs" row of cards with a play-button overlay
- A footer with link columns

## Run
Open `index.html` in a browser. Font Awesome loads from cdnjs, and the artist images load from external URLs.

## Files
- `index.html`: markup
- `style.css`: styles
- `script.js`: empty for now
